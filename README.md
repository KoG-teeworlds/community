# KoG Community

## Use of Issues
We use issues in this repository for the following:
- To coordinate the project
- To log community discussions and projects
- For suggestions on improving community processes

## Reporting a bug
Found something that does not work on the website, the game servers or a map?
[Open a bug report](https://github.com/KoG-teeworlds/community/issues/new?template=bug_report.yml).
The website's "Report a bug" links lead to the same form, with the page you were on filled in.
Open bugs are listed under [issues labelled `bug`](https://github.com/KoG-teeworlds/community/issues?q=is%3Aissue+is%3Aopen+label%3Abug),
and the website shows them as "Known issues".

Not for the bug form: security problems (see [SECURITY.md](SECURITY.md)), and anything about a ban
or your account, which is handled privately through a ticket on the website.

If you have any question, feel free to ask on [our discord](https://discord.kog.tw)
